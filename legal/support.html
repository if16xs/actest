الدعم والطلبات القانونية

استخدم هذه الصفحة لتحديد نوع الطلب والمعلومات المطلوبة قبل التواصل، بما يسرّع المراجعة ويحافظ على سلامة البيانات.

آخر تحديث: 1 أغسطس 2026قناة حالية: GitHub
لا ترسل كلمات المرور أو رموز الدخول أو مفاتيح API أو مفاتيح التراخيص الكاملة ضمن البلاغات العامة.
أنواع الطلباتدعم فنيطلب خصوصيةحقوق ملكيةبلاغ أمنيترخيص تجاريطريقة التواصل

1. الدعم الفني

اذكر اسم المنتج وإصداره، نظام التشغيل، وصف المشكلة، خطوات تكرارها، السجلات ذات الصلة، وما إذا كانت المشكلة بدأت بعد تحديث أو تعديل معين.

2. طلبات الخصوصية

حدد المنتج ونوع الطلب: وصول، تصحيح، حذف، اعتراض، أو استفسار. قد يطلب إثبات مناسب للهوية أو ملكية الحساب قبل الإفصاح عن البيانات أو تعديلها.

3. بلاغات الملكية الفكرية

أرفق وصف العمل المحمي، رابط المادة محل البلاغ، أساس ملكيتك أو تفويضك، وبيانًا بأن المعلومات المقدمة صحيحة. البلاغات الناقصة قد تتطلب معلومات إضافية.

4. البلاغات الأمنية

قدم وصفًا واضحًا للثغرة، المنتج والإصدار المتأثر، خطوات إثبات محدودة وآمنة، والأثر المتوقع. لا تنشر تفاصيل الاستغلال علنًا ولا تصل إلى بيانات لا تخصك.

5. التراخيص والاستخدام التجاري

اذكر المنتج، نوع النشاط، عدد المستخدمين أو الخوادم المتوقع، نطاق التوزيع، مدة الترخيص المطلوبة، وأي احتياج للتخصيص أو إعادة العلامة التجارية.

6. طريقة التواصل الحالية
