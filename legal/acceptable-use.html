1. الأنشطة المحظورة

  • استخدام الخدمة في الاحتيال أو انتحال الهوية أو التهديد أو التحرش أو نشر محتوى غير مشروع.
  • إرسال الرسائل المزعجة أو إساءة استخدام البوتات أو الأتمتة لإغراق الخدمات.
  • تجاوز حدود الاستخدام أو القيود التقنية أو أنظمة الترخيص.
  • توزيع برمجيات ضارة أو سرقة بيانات أو مفاتيح أو جلسات دخول.
  • التعدي على حقوق الملكية الفكرية أو الخصوصية أو حقوق الآخرين.
  • استغلال المنتج لإفساد خوادم الألعاب أو إلحاق الضرر باللاعبين أو بالبنية التحتية.

2. الاختبارات والأمن

لا يجوز فحص الثغرات أو تنفيذ اختبارات اختراق أو تحميل ضاغط على أنظمة Final Touch أو مستخدميها دون تصريح مكتوب يحدد النطاق والمدة. يجب الإبلاغ المسؤول عن الثغرات دون نشر تفاصيل قابلة للاستغلال قبل معالجتها.

3. الالتزام بشروط المنصات

عند استخدام تكاملات Discord أو GitHub أو Steam أو الألعاب أو مزودي الاستضافة، يلتزم المستخدم كذلك بشروط تلك الجهات وسياساتها وحدود واجهاتها البرمجية.

4. إجراءات المخالفة

قد تشمل الإجراءات التحذير، تقييد المزايا، تعليق الحساب أو الترخيص، حظر الوصول، حذف المحتوى، أو إحالة المخالفات الجسيمة إلى الجهة المختصة. يراعى نوع المخالفة وخطورتها وتكرارها.

للإبلاغ عن إساءة استخدام، استخدم صفحة الدعم والطلبات القانونية.
