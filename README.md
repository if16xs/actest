# Final Touch GitHub Page

موقع تعريفي احترافي لفريق **Final Touch Team**، مبني كتطبيق ثابت سريع ومتجاوب، وجاهز للنشر عبر GitHub Pages.

## محتويات الموقع

- واجهة افتتاحية احترافية.
- قسم من نحن ومبادئ العمل.
- كاردات الخدمات والتخصصات.
- قسم المشاريع المختارة.
- آلية العمل من التحليل حتى الإطلاق.
- روابط GitHub والموقع الرسمي.
- دعم كامل للجوال والتابلت والكمبيوتر.
- تصميم عربي من اليمين إلى اليسار.

## تفعيل GitHub Pages

1. افتح المستودع في GitHub.
2. ادخل إلى `Settings`.
3. من القائمة الجانبية اختر `Pages`.
4. عند `Build and deployment` اختر `Deploy from a branch`.
5. اختر الفرع `main` والمجلد `/ (root)`.
6. اضغط `Save`.

بعد اكتمال النشر سيظهر رابط الموقع داخل صفحة Pages.

> تنبيه: المستودع يجب أن يكون عامًا لاستخدام GitHub Pages مجانًا. غيّر الخصوصية من: `Settings → General → Danger Zone → Change repository visibility`.

## الرابط المقترح

في الوضع الحالي، بعد جعل المستودع عامًا وتفعيل Pages:

`https://if16xs.github.io/actest/`

للحصول على الرابط الرئيسي القصير:

`https://if16xs.github.io/`

يجب تغيير اسم المستودع إلى:

`if16xs.github.io`

## ربط النطاق finaltouchdev.com

بعد التأكد من عمل الموقع:

1. من `Settings → Pages` أضف `finaltouchdev.com` في `Custom domain`.
2. في مزود DNS أضف سجل `CNAME` للنطاق الفرعي `www` يشير إلى `if16xs.github.io`.
3. أضف سجلات GitHub الرسمية للنطاق الأساسي حسب التعليمات الظاهرة في صفحة Pages.
4. فعّل `Enforce HTTPS` بعد اكتمال التحقق.

## التخصيص

- النصوص والأقسام: `index.html`
- الألوان والتصميم: `assets/style.css`
- المؤثرات والتفاعل: `assets/app.js`
